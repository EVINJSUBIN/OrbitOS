# OrbitOS 2.0

This is my second operating system project made for Hack Club. I rebuilt it from the ground up using React and Vite to make it run completely in the browser.

## How to run it locally

1. Download or clone this repository
2. Open your terminal in the project folder
3. Type `npm install` to get the dependencies
4. Type `npm run dev` to start the server
5. Open the link it gives you in your browser

## Features

- A full-width space taskbar at the bottom
- Live ISS tracker app that pulls real satellite data
- Built-in AI assistant called Orbit AI
- Basic file manager and terminal apps
- Space-themed wallpapers and custom UI

That's everything. Feel free to explore the code.
