# Orbit OS !! 🌌

hi welcome to my OrbitOS!! this is my project for the hackclub stardance webOS-1 mission. 
i made a space themed operating system that runs entirely in the browser.

## stuff it can do

- **dragable windows:** u can click the top of the apps and move them around the screen!
- **bring to front:** if u click an app it comes to the front so u can see it better
- **cool background:** it has a space background and a taskbar with a working clock at the bottom
- **notepad app:** u can type notes here and it saves them so if u refresh they are still there! (uses localstorage)
- **web browser:** a small browser inside the browser lol. u can go to websites using the adress bar.
- **ISS Tracker:** this is my unique app! it connects to a free API and shows exactly where the international space station is right now and how fast its going!!

## how to play with it

its really simple and u dont need to install anything. 
just download the files and double click `index.html` to open it in chrome or whatever browser u use.
then just double click the icons on the desktop to open the apps.

## how i built it
i used standard HTML, CSS and Javascript. it was kinda hard to make the windows draggable and get the z-index stuff working right but i finally figured it out!

hope u like it!!
