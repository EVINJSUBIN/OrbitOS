# Orbit OS 2.0
my second operating system made for hack club. this time its way cooler

## how to run it
1. download the code
2. open ur terminal and type `npm install`
3. type `npm run dev`
4. open the localhost link it gives u in ur browser

## whats inside
- cool space taskbar at the bottom
- real live iss tracker app
- orbit ai assistant built in
- file manager and terminal
- space wallpapers

thats it enjoy!
